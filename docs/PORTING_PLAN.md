1. Humble topic, TF, teker ve geometri sözleşmelerini koru.
2. Jazzy/Harmonic Docker ortamında izole build yap.
3. Topic tabanlı robot description, spawner parametreleri ve TwistStamped zincirini doğrula.
4. Harmonic robot spawn, controller lifecycle, altı temel hareket, odometry, TF, LiDAR ve IMU testlerini çalıştır.
5. Mapping, map save ve kayıtlı harita Nav2 akışını headless doğrula.
6. Ubuntu 24.04 native ve Pi 5 mock hardware yollarını doğrula.
7. Kullanıcı donanım değerlerini sağladığında udev, sensör ve gerçek araç kalibrasyonunu tamamla.
